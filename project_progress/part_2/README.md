# Part 2: Indexing and Evaluation

Part 2 is implemented in [`part2.ipynb`](./part2.ipynb). It uses the documents
processed in Part 1 (`../part_1/processed_docs.json`), so that file must exist
before running the notebook.

## 1. Prepare the environment

From the repository root, activate the virtual environment and install the
packages used by the notebook:

```bash
python -m venv irwa_env
```

```bat
irwa_env\Scripts\activate
```

```bash
python -m pip install nltk numpy pandas matplotlib ipykernel
```

## 2. Run the notebook

Open [`part2.ipynb`](./part2.ipynb) in VS Code, select the environment as the
kernel and use **Run All**. To use Jupyter from a terminal, start it inside
`project_progress/part_2`, because the notebook uses relative paths.

## 3. Files

- `myapp/search/algorithms.py`: query pre-processing, inverted index,
  conjunctive (AND) search and TF-IDF ranking.
- `myapp/search/evaluation.py`: P@K, R@K, F1@K, AP@K, MAP, RR, MRR and NDCG.
- `part2.ipynb`: experiments, results and analysis.
- `test_labels.csv`: relevance labels of the five test queries, in the same
  format as `validation_labels.csv`. It is written by the notebook.
- `evaluation_output/`: figures generated by the notebook.

## 4. Changing the search

Edit `TEST_QUERIES` in the notebook to change the queries, and
`RELEVANCE_RULES` to change their judgments. To index another field, pass it to
`create_tfidf_index(docs, field="title_terms")`. Run all the cells again after
any change.
